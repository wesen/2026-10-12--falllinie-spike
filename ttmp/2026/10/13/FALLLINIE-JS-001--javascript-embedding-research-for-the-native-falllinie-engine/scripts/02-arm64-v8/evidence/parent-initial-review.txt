### Findings

- **P2 — Logging contaminates some reported durations.**  
  At `P/probe-common.hpp:31,44,58`, `us(a)` is evaluated *after* preceding `std::cout` insertions. Thus source-read, first-call and explicit-GC timings include formatting/output work and potentially a buffer flush. This is particularly material to very short first-call measurements. Warm distributions capture their endpoint before logging and are unaffected.  
  **Smallest fix:** Capture elapsed values immediately after the measured operation, then print them. Preserve old evidence and generate clearly identified replacement receipts.

- **P2 — Finite inputs can produce an accepted nonfinite native result.**  
  `CopyState::copy` checks each element but not the accumulated sum (`P/probe-common.hpp:23`). Two `Number.MAX_VALUE` elements pass validation, overflow the sum to infinity and commit that value; both embeddings return it (`P/quickjs-probe.cpp:27`; `P/v8-probe.cpp:23–24`). This does not affect the supplied deterministic fixtures, but leaves a gap in the new numeric boundary qualification.  
  **Smallest fix:** Reject a nonfinite accumulated result before committing copied state; add an overflow rejection test that also verifies prior copied state remains intact.
