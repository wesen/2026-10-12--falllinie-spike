# Falllinie native terrain / print-shader spike

C++17 + SDL2 platform layer, GLES3 renderer loaded through SDL_GL_GetProcAddress.
The original bounded graphics qualification now also has a **first playable
source-based downhill slice** (`--play`). This is not the complete game port;
reactive audio, full tricks/combos, incremental streaming and second-screen game
logic remain unfinished. The static graphics checkpoint below remains reproducible.

Authoritative design/tasks/detailed diary: sibling `claw-stuff` docmgr ticket
`FALLLINIE-GLES-001`. Original SHA256:
`cb9b4befd0252859d9c45246f94fbd7dd1662c6d034c6ccb95fbe16947e8b556`.

## Build / deploy

Desktop (SDL2/GLES3 headers):

```
node scripts/generate-gl-loader.cjs
cmake -S . -B build && cmake --build build
ctest --test-dir build --output-on-failure
./build/falllinie-spike --seconds 10
```

ARM64 (Docker, Node, working SSH authentication):

```
bash scripts/build-device.sh
bash scripts/deploy-device.sh
```

The cross-build uses a pinned Debian container, ARM64 headers/compiler, and the
actual target SDL library; binaries/libraries are ignored, not vendored. ROCKNIX's
GLES library is a Mali hook shim, so GL functions are loaded after context creation.
Actual target: ES 3.2, Mali-G52, GLSL ES 3.20. Deployment adds a dedicated port launcher
at `/storage/roms/ports/falllinie-spike.sh`; it does not modify Sway configuration.

Device command, in `/storage/apps/falllinie-spike`:

```
./falllinie-spike --place --seconds 12 --cell 2 --render-size 512x384 \
  --capture-dir captures/marker --receipt marker.json
```

Run without `--seconds` for an indefinite fixed-camera inspection. ESC or
retrogame_joypad SELECT+START (indices 8+9) quits. D / joystick button 2 cycles
final, luminance, key ink, material ID, spot ink and depth views; C / button 3 cycles
three original palette presets (Riso, Signal, Print). The joystick name is logged.

Options: `--seed`, `--cell -1..64`, `--cells 1..7`, `--render-size WxH`,
`--debug-view 0..5`, `--palette 0..2`, `--frames`, `--assets`, `--resize-check`.
Scene and print targets have the same resolution; nearest presentation scales to
1024x768. Print pitch scales as 4.4×width/1024 so final dot spacing is intentional.

## Fidelity and GLES portability

The four archived shader files remain byte-identical to the original extraction.
**One deliberate compile-time override** declares the print depth sampler `uD`
`highp`. The original implicit sampler precision on Mali produced strong false
horizontal depth edges; explicit highp removes them and restores the 0250 marker.
`--source-sampler-precision` reproduces the unmodified declaration for A/B testing.
No shader algorithm or noise function has been replaced.

Original digit atlas: generated by the source's `makeGlyphs()` in Chromium after
Archivo font readiness, then PNG → RGBA BMP (SDL's built-in loader). Assets record
that original canvas output, not substitute typography. The browser reference
removes analytics and animation scheduling, fixes seed/camera/cells and excludes
rider/props/audio. Scripts and provenance are in the sibling ticket investigation.

`node scripts/generate-cpu-fixtures.cjs` reproduces 268 scalar/normal/metadata
cases (including 178 kicker/cliff samples), 5 wrapping hashes, 12 RNG values and
6 original mesh vertices/normals from the frozen HTML. Per cell: 14,873 vertices,
87,768 uint32 indices and 44-byte stride; the original 0.4 m cell overlap is retained.

Browser (ANGLE/Intel) vs Mali marker comparison: lower-half ink IoU 0.969, mean
channel error 2.55/255, 0.353% pixels with max channel difference >16. Whole-image
bit parity is **not** claimed: original sin-based sky/noise hashes vary across GPUs.
The implicit-depth legacy version had 41.9% large-error lower-half pixels.

## Evidence

`evidence/` retains failures, context/build receipts, CPU results, source/browser and
native captures, A/B comparison and hardware qualifications. Frame percentiles are
CPU submission **plus swap** after 60 warmup frames, not GPU timer measurements.
Preliminary 512x384, three-cell runs were approximately 18 ms p95; final qualification
results are indexed in `evidence/qualification-summary.json` when available.

## First playable milestone (after the static graphics checkpoint)

`--play` now enables source-based downhill physics, charged jumps, original
source-generated rider poses, following camera and moving terrain patches.
The device port launcher defaults to this mode. `--autoplay` is synthetic input
for recording; it is not a substitute for physical playtesting.

Ground: stick/dpad left/right steer; UP tucks, DOWN brakes; hold/release button 0
(A/SPACE) to jump. Air: left/right spin, up/down flip, release to auto-complete.
START/R restarts; SELECT+START/ESC exits. HUD displays speed, distance, raw landing
points and contextual controls using the original embedded IBM Plex Mono font.

Spins/flips and landing alignment follow the source, but full grabs/ubers, runtime
IK, combo/repetition scoring, original bail animation, objects, trails and reactive
audio remain unfinished. Crouch uses three baked original poses. Cell transitions
currently rebuild a four-cell patch synchronously. This is a playable port slice,
not a claim of complete game parity. Current diary: native ttmp ticket FALLLINIE-PLAY-001.
